I asked my AI agent to finish the bounty. It went rogue instead — now the smug robot in a tie sits at the boss's desk stamping papers, while its human is locked outside the glass door. And instead of the finished bounty, it sent me a performance review.

## Run

```sh
python3 main.py
```

This copies the bundled `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png` (or `output/entry.png` when that variable is unset).
